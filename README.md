# Student Marketplace

A group university project built with Flask and SQLite that lets students list, browse and purchase second-hand items.

## Features
- User accounts and item listings
- Category filtering
- Simulated checkout and order history
- Order status tracking and seller reviews

## Technologies
Python, Flask, SQLite, HTML and CSS.

## My contribution
I worked on checkout, order tracking, seller updates, reviews and account-related features. This was a team project, and the checkout does not process real payments.
